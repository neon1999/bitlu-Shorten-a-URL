# bitlu

Turn long web addresses into short links that are easy to share.

[Open bitlu](https://bitlu.netlify.app)

## Shorten a link

1. Open bitlu and paste a web address into **Destination URL**.
2. Select **Shorten link**.
3. Select **Copy link**, then share the short link wherever you like.

You can enter a full `https://` or `http://` address, or a domain such as `example.com`. If you leave off the scheme, bitlu uses HTTPS. Only web addresses using HTTP or HTTPS are supported.

## Recent links

Your eight most recent links appear in **Recent links** on this browser. This history is saved on your device. Select **Clear** to remove it. Clearing the history does not deactivate links you have already shared.

## About your links

When you create a short link, its destination address is sent to bitlu and stored so the short link can redirect visitors to it. Recent-link history is stored locally in your browser.
